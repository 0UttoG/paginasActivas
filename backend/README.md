# Backend de Paginas Activas

API inicial creada con Node.js, Express, PostgreSQL, `pg` y `dotenv`.

1. Copia `.env.example` como `.env` y completa la conexión a PostgreSQL.
2. Ejecuta `npm install`.
3. Ejecuta `npm run dev`.
4. Consulta `http://localhost:3000/health`.

El esquema de la base de datos se encuentra en `database/schema.sql`.
